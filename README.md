# Mini Projects & Experiments

A collection of smaller projects, practice exercises, and experiments built while learning and applying software development and machine learning concepts.

These projects are kept together as a learning archive. They are not presented as production-ready applications.

## Repository Structure

```text
Mini-Projects-and-Experiments/
├── Frontend-Experiments/
│   ├── Personal-Portfolio-Website/
│   ├── Pro-Food-Landing-Page/
│   └── Floral-Boutique-Landing-Page/
├── Machine-Learning-Experiments/
│   ├── KNN-Risk-Evaluation/
│   └── Sales-Forecasting/
└── README.md
```

## Front-End Experiments

| Project | Description | Main Technologies |
| --- | --- | --- |

| [Pro Food Landing Page](Frontend-Experiments/Pro-Food-Landing-Page/README.md) | A static restaurant/food landing page focused on page layout and styling. | HTML, CSS |

## Machine Learning Experiments

| Project | Description | Main Technologies |
| --- | --- | --- |
| [KNN Risk Evaluation](Machine-Learning-Experiments/KNN-Risk-Evaluation/README.md) | An educational notebook exploring K-Nearest Neighbors for a risk-evaluation task. | Python, Pandas, scikit-learn, Jupyter |

## Notes

- These projects are learning experiments and should not be treated as production systems.
- Some original image, font, and dataset assets are referenced from their original repositories to avoid duplicating large binary files in this archive.
- The original repositories are retained as source copies until this consolidated archive has been checked.
- Notebook results should be regenerated before quoting performance metrics.
- Load serialized model files such as `.pkl` only from trusted sources.
